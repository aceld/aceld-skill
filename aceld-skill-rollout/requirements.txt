# aceld-skill-rollout 无第三方依赖，Python 3.8+ 标准库即可
#
# 用到的标准库：
#   argparse / os / re / sys / filecmp / shutil / time
#
# 依赖的其它技能（不是 pip 包，是同级技能）：
#   aceld-findskill   —— 块内引用的 preflight.py 来自它；没装则前置检查那一步跑不了
#
# 环境变量：
#   ACELD_SKILL_REPO   —— aceld-skill 仓库根路径。不设则从当前目录向上找
#                        aceld-course/skill/SKILL.md 来定位
#   https_proxy / http_proxy  —— 只在 git push 时需要，国内走 http://127.0.0.1:7890
