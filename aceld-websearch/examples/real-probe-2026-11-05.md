## 3. 逐条核验（WebFetch 实测）

### 候选 ① 腾讯云开发者社区

`https://cloud.tencent.com/developer/article/2701441` — 《从"对话"到"行动"：2026年AI Agent工程化落地实录与MCP协议实践》

| 核验项 | 结果 |
|---|---|
| 发布日期 | ✅ 页面标注「发布于 2026-07-01 18:12:53」，在窗内 |
| 正文可读 | ✅ 抓到 10+ 段实质正文（含完整代码示例），无需登录 |
| 作者 / 层级 | ⚠️ 署名「用户12583550」，社区投稿；域名已补进 T2 表 |
| **公开计数** | ❌ **页面没有公开阅读量 / 点赞 / 评论 / 收藏计数** |

**判定：淘汰**。理由写进 `pack.md` 的淘汰留痕应是「指标不可得（页面无公开计数）」。
**不能**因为「这文章读起来很专业」就把 `metrics_verified` 打勾，也不能拿搜索摘要里的
任何热度字样凑数。用户要的是「高指标」，没有可核验的高指标就是不合格。

### 候选 ② B站视频

`https://www.bilibili.com/zh-Hant/video/BV1xonm6wEAP/` — 《渐进式披露下的 Agent Skills 教程》

| 核验项 | 结果 |
|---|---|
| 页面响应 | ❌ `出错啦! - bilibili.com / 错误号: 412 / 触发安全风控策略` |
| 发布日期 / 播放 / 评论 | ❌ 全部抓不到 |

播放量、评论数再高也**无法核验**，更无法保证下游能打开。不要硬塞进资料包。
