# 07 · 封面（横版 + 竖版）

## 1. 两版尺寸

| 平台 | 尺寸 | 说明 |
|---|---|---|
| B 站 / YouTube 缩略图 | 1146 × 717 | 16:10，站内推荐位就是这个比例 |
| 抖音 / 视频号 / 小红书视频 | 1080 × 1920 | 9:16 竖屏 |

一套设计语言出两版，只调整布局密度。

## 2. 设计系统（深色科技风）

```
背景：linear-gradient(140deg, #070b16 0%, #0d1428 48%, #141d38 100%)
      + 3 个径向光斑（青 #22d3ee / 紫 #a78bfa / 金 #fbbf24）
      + 64px 网格线 rgba(120,160,220,.13)
```

元素层级（从上到下）：

| 元素 | 样式 |
|---|---|
| 系列角标 | 青描边胶囊，`《系列名》系列` |
| 课次 | 金色，`第 N 课 · XX 篇` |
| 主标题 | 900 字重白色，96px，**一个关键词染金** |
| hook | 白色 800 字重，40px，含一个金色强调 |
| sub | 灰色 600 字重，23px，罗列具体内容 |
| 标签 | 胶囊，4 个，青 / 金 / 紫 / 描边轮换 |

**主标题最多两行，第二行不超过 10 个汉字。** 超过就要拆句或缩短。

## 3. 文案公式

封面不是标题，是**钩子**。三种有效结构：

| 结构 | 例 |
|---|---|
| 反常识陈述 | 大模型不是笨，是「记不住」你 |
| 门槛消除 | 不会写代码，也能做出 AI 应用 |
| 身份对照 | 大模型是脑，Agent 是脑加手脚 |

配套 hook 必须给**具体数字**：

- ✅ `31 分钟，把智能体的记忆六代一次讲透`
- ❌ `深入浅出讲解智能体记忆`

sub 行用来「证明内容够硬」，罗列具体名词：`ReAct · Plan-and-Execute · Reflection · Multi-Agent`

标签行用来「证明门槛够低」：`0 行代码 / 4 毛钱成本 / 全程本地 / 0 基础也能懂`

### 3.1 系列课的主标题要能构成递进

如果是一个系列，主标题之间应该有逻辑关系，而不是各说各的：

```
第 1 课：不会写代码，也能做出 AI 应用      ← 门槛
第 3 课：大模型是脑，Agent 是脑加手脚       ← 概念
第 4 课：大模型是大脑，干活靠「五脏六腑」    ← 拆解
第 5 课：大模型不是笨，是「记不住」你       ← 追问
```

观众刷到任意一张，都能感觉到「这是同一套东西的第几层」。

## 4. 竖版：底部 20% 是雷区

抖音/视频号的底部会被标题、作者、按钮、进度条盖住。

**规则：所有内容收在整图高度 ~78% 以内。**

| ❌ 做法 | ✅ 做法 |
|---|---|
| 标签组用 `margin-top:auto` 贴底 | 固定 `margin-top:56px`，紧跟上一个块 |
| 内容撑满 1920 | 内容下沿落在 1450~1510 |

自查：渲染完量一下最底部元素的下沿 y 坐标，`y / 1920` 应该 ≤ 0.79。

## 5. 竖版布局（六行发光节点列表）

比横版多一个「信息清单」块，用来把课程结构一次说完：

```
● 四次更迭 · 人写规则 → 自己悟
● 三块基石 · 算法 · 数据 · 算力
● 它只干一件事 · 预测下一个词
● 为什么会幻觉 · 它没有「不知道」
● 文字是坐标 · 12288 维空间
● 涌现 · 99℃ 是水，100℃ 是蒸汽
```

样式：

- 左侧一条竖向渐变线（青→紫→金）
- 每行一个发光圆点，颜色按行轮换
- 字号 41~42px，**最长一行不超过 20 个汉字**

最后一块是**点题框**：金左边框 + 淡金渐变底，一句话收束。

```
差的不是智力
是手脚
```

## 7. 生成脚本

`make_cover.py` 用 Playwright 渲染 HTML 后截图：

```python
with sync_playwright() as p:
    b = p.chromium.launch(channel="chrome")      # 或 msedge / chromium
    pg = b.new_page(viewport={"width": w, "height": h}, device_scale_factor=1)
    pg.goto("file:///" + tmp.replace("\\", "/"))
    pg.wait_for_timeout(1500)                     # 等字体加载
    pg.screenshot(path=png)
```

要点：

- `device_scale_factor=1`（画布已经是目标尺寸，不需要再放大）
- `wait_for_timeout(1500)` 不能省，否则字体没加载完就截图，字会变成方框
- 中文字体名写 `"Microsoft YaHei","PingFang SC"`，两个都写上
