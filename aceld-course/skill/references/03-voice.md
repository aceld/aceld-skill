# 03 · 配音（CosyVoice2 零样本克隆）

> 这一章是整套流水线里**返工最多**的部分。一个真实案例：同一节课在语音上返工 8 轮、约 12 小时，
> 其中 6 轮本可以一次做对——根因不是技术难，是**没有交付前的自动验收**。
> 铁则：**配音跑完先跑第 7 节的验收，全绿才允许渲染。**

## 1. 为什么用 CosyVoice2

早期用 F5-TTS，有三个无法通过调参解决的死结：

1. 复读参考音频尾部（每句结尾补一段参考音频里的话）
2. 字间断裂频繁（每百字 4~5 次，听起来像「发邮(停)件给老板」）
3. 「说得慢」和「不复读」互斥——降速必复读

试过 cfg / nfe / 重新切分 / 缝合 / 换 4 段参考，全部无效。换 CosyVoice2 后三个问题一起消失，RTF 从 1.5 降到 0.6。

## 3. 参考音频（决定全片音质）

### 3.1 要求

| 项 | 要求 |
|---|---|
| 时长 | 8~12 秒 |
| 内容 | 正常语速的一段完整话，**说完最后一个字就停** |
| 首尾 | 干净。不要硬切、不要留孤立杂音 |
| 环境 | 单人、无背景音乐、无回声 |
| 采样率 | 16k 以上（脚本会重采样到 16k） |

### 3.2 ★切点必须用词级 ASR 时间戳卡

**不能用能量阈值切。** 阈值会把弱起音误判成静音，切在字中间 → 模型认为话没说完 → 复读那半句。

```python
# 用词级 ASR 找到最后一个字的结束时间
# 在其后留 ~130ms，切掉后面的孤立杂音
# 首尾各加 8ms 淡入淡出
```

参考末尾**绝不能含下一个字的半截音**。「支持 AP」「有战术或计策」这类句尾怪音，全部来自参考音频尾巴不干净。

### 3.3 换参考音频是治本，事后清理是治标

如果成片里句号处总冒出固定的怪音（某个词、某个音），先怀疑参考音频：

1. 用 ASR 词级时间轴确认参考音频真正说到哪里
2. 在最后一个字之后留 130ms，切掉后面的孤立杂音
3. 首尾各加 8ms 淡入淡出
4. 参考文本只保留切剩下的部分

→ 怪音直接消失，不用事后处理。

**走过的弯路（别重复）**：以为是 ASR 幻觉（查波形发现有真实时长）→ 以为是换气声（实测谱平坦度和正常语音一样）→ 事后用 insert 检测 + 静音打补丁（能压下去，但每清一轮又冒新的，而且把语句切得一顿一顿）。

## 4. 参数（定稿，别乱调）

| 参数 | 值 | 说明 |
|---|---|---|
| `speed` | **1.0** | ★必须。CosyVoice 的 speed 是 `F.interpolate(tts_mel, mode='linear')`，对频谱线性拉伸；0.6 拉长 1.67 倍 → 发闷发糊，调不回来 |
| `gap_sent` | 0.60 | 段间停顿（秒） |
| 传参方式 | **整段一次性传入** | 内部按标点自然切分并停顿，不要手动切句再拼 gap |
| 实测语速 | 250~360 字/分 | 由参考音频语速决定 |

**要更慢怎么办？** 不要动 speed。改讲稿：句子写短、加逗号、加过渡词。
或者接受「按正常语速」。

## 5. 后处理三步（少一步就有杂音）

```python
def _prep(a, sr):
    a = a - float(a.mean())      # ① 去 DC 偏移
    a = trim(a, sr)              # ② 裁静音（头严尾宽）
    return _fade(a, sr, 6)       # ③ 首尾 6ms 淡化
```

| 步骤 | 缺了会怎样 |
|---|---|
| ① 去 DC | 拼接处基线跳变 |
| ② 裁静音 | 阈值太松 → 句首一声「杂质」 |
| ③ 6ms 淡化 | 拼接点波形阶跃 → 「啪」的爆音 |

### 5.1 ★头部严、尾部宽（这是最容易搞反的一处）

```python
def trim(a, sr, thr_ratio=0.08, pad_ms=6, run=3,
         tail_ratio=0.015, tail_pad_ms=40):
    win = int(sr * 0.01)
    n = len(a) // win
    e = np.sqrt(np.mean(a[:n*win].reshape(n, win)**2, axis=1))
    peak = float(e.max()) or 1.0

    # 头部：阈值 0.08（约 -22dB）+ 要求连续 3 帧超阈值
    on = e > max(peak * thr_ratio, 0.01)
    start = next((i for i in range(len(on) - run + 1) if on[i:i+run].all()), None)

    # ★尾部：阈值 0.015（约 -34dB），比头部宽得多
    on_tail = e > max(peak * tail_ratio, 0.004)
    end = next((i + 1 for i in range(len(on_tail) - 1, -1, -1) if on_tail[i]), None)

    if start is None or end is None or end <= start:
        return a
    pad, tpad = int(sr*pad_ms/1000), int(sr*tail_pad_ms/1000)
    return a[max(0, start*win - pad): min(len(a), end*win + tpad)]
```

- 头部阈值 0.02（≈-34dB）太松 → vocoder 的残留噪声被当语音起音 → 句首「杂质」
- 尾部用 0.08 太严 → 句末轻声（的 / 了 / 干 / 停）被当静音裁掉 → 系统性丢字
- 判别依据：真起音峰值 0.75~0.90，噪声只有 0.062~0.077（差 10 倍）

### 5.2 ★淡出用 6ms，不是 28ms

28ms 淡出会把句末弱尾音一起削掉。实测 42 段里有 38 段出现「最后几个字没了」。

## 6. 发音替换表（只改送模型的文本）

`meta.json` 里同时存 `text`（原文，给字幕）和 `tts`（替换后，给对齐）。
**字幕永远显示原文**，只有送进 TTS 的文本被替换。

```yaml
# course.yaml
voice:
  repl:
    # 英文音译：挑实词，不要用语气词
    - ["Harness", "哈内斯"]
    # 分开拼写才读得准
    - ["sandbox", "Sand Box"]
    - ["workflow", "Work Flow"]
    # 多音字：转 zhuàn（全部是「转圈」义）
    - ["转圈", "赚圈"]
    - ["转起来", "赚起来"]
    # 多音字：行 háng（只在「X 行」里）
    - ["一千行", "一千航"]
    - ["四十行", "四十航"]
```

替换后要清掉中文之间多余的空格：

```python
t = re.sub(r"(?<=[\u4e00-\u9fff])\s+(?=[\u4e00-\u9fff])", "", t)
```

### 6.1 其他常见多音字

| 字 | 错读 | 修法 |
|---|---|---|
| 行 | xíng | 「X 行」→「X 航」；「行业」→「业界」 |
| 重 | zhòng | 重新/重试/重复 → 再/反复 |
| 转 | zhuǎn | 转圈/转起来 → 赚 |
| 弹 | dàn | 弹窗 → 谈窗 |
| 量 | liàng | 量一量 → 良一量 |
| 长 | zhǎng | 长对话 → 常对话 |
| 攒 | cuán | 没有合适同音字 → **直接换词**（「攒起来」→「积得起来」） |
| 闸 | zhǎ（三声） | 标准读 **zhá（二声）**，模型默认读三声 → 「闸门」→「札门」 |

**规律：能换词就换词，换不了才音译。** 硬凑音译比换词难听得多。

## 7. 英文单词：完整决策树

```
英文单词怎么读？
├─ 换引擎（edge-tts / 微软音色）        ❌ 音色断
├─ 切出单词单独 cross_lingual          ❌ 没上下文乱读
├─ 整段 cross_lingual                  ❌ 音色漂
├─ 新录英文参考 + cross_lingual        ❌ 音色不是同一个人的
└─ ✅ 原参考 + zero_shot + 替换表
     ├─ 音译（挑实词）：Harness → 哈内斯
     └─ 分开拼写：sandbox → Sand Box / workflow → Work Flow
```

**源码级根因（记死，别再翻）**：
`cross_lingual` 相比 `zero_shot` 删掉了 `llm_prompt_speech_token`。这个 token 序列**同时**编码
「音色细节」和「中文音素」：

- 留着 → 音色对，但英文按中文音素读
- 删掉 → 英文对，但只剩粗粒度 speaker embedding，音色和韵律一起漂

**没有第三条路。** 所以优先级永远是：**音色 > 英文标准度**。宁可英文略偏，不能音色漂。

### 7.1 音译选字规则（实测）

| 写法 | ASR 结果 | 判定 |
|---|---|---|
| 哈呢斯 | 那内斯（「哈呢」被吞） | ❌ 语气词会被弱化吞掉 |
| 哈尼斯 | 哈里斯 | ❌ |
| **哈内斯** | 哈内斯 | ✅ |
| 哈耳尼斯 | 哈尔尼斯（4 音节偏长） | 备选 |

→ **音译必须用实词（内/尼/耳），绝不能用语气词（呢/吧/啊）。**

### 7.2 分开拼写实测

| 写法 | ASR | 结论 |
|---|---|---|
| `Sand Box` | sandbox | ✅ |
| `Work Flow` | workflow | ✅ |
| `token` | token | ✅ |
| `schema` | ski | ⚠️ 天花板 |
| `Max Turns` | MAX TRANCE | ⚠️ 天花板 |

**接受现实**：某些词在这个音色下就是读不准，别再折腾。观众能听懂就行。

### 7.3 ★英文整词「一个字一个字蹦」时：按语言切段，英文走 cross_lingual

用户的原话是「**anthropic 这个单词要读快一些，否则中文汉字一个一个地蹦，太突兀**」。

这是 `zero_shot` 读英文的典型症状：模型把 `Anthropic` 按中文音素拆成「安-思-罗-匹-克」五个等长音节，
每个音节都占一拍，听起来像在念汉字，跟正常说话的连读节奏完全不同。

**修法**：把整段文本按语言切分，**中文段走 `zero_shot`（最像本人），英文段走 `cross_lingual`（按英文连读）**：

```python
def speak(text):
    text = apply_repl(text)          # ★ 先替换再切分
    out = []
    for lang, piece in split_lang(text):
        out.append(_gen_en(piece) if lang == "en" else _gen_zh(piece))
    return np.concatenate(out)
```

**三个必须注意的点**：

1. **先 `apply_repl` 再切分**。否则 `Aceld → 阿塞尔德` 这种音译会被当成英文词，走错分支。
2. **英文段要带上下文**，不能只把孤立单词丢进去（孤立单词 `cross_lingual` 会乱读，见上方决策树）。
   按整句切出来的英文短语（`Anthropic 那份报告`）是安全的。
3. **音色漂移只发生在英文那几个词上**，混在中文句子里几乎听不出。
   实测整段产出 336 字/分，比原来全 `zero_shot` 的 300 字/分更快，正好符合「读快一点」的诉求。

**判断标准**：如果一个英文词被读成了「等长的几个汉字音节」，就该切；
如果 `zero_shot` 下已经能连读（`token`、`schema` 这类短词），就不用切，省事。

## 8. 连贯性：整段一次生成，不要打补丁

三个破坏连贯性的做法（都要避免）：

| 做法 | 后果 |
|---|---|
| 按 110 字切块、每块独立推理 | 每块语调重置，块间静音 → 听起来一段一段 |
| 词间空隙归零（停顿门） | 字与字之间被硬切 → 一顿一顿 |
| 事后大量静音补丁 | 同上，且每轮引入新的不连续 |

正确做法：

```
1. 每段讲稿整段一次推理（段均 300 字左右 → 基本一块就够）
2. 真需要切块时，块间静音压到 0.12s
3. 不做任何词间静音处理
4. 首尾多余音节只切头尾，不碰中间
```

**连贯性怎么量**：

```python
gaps = [ws[i+1][1] - ws[i][2] for i in range(len(ws)-1)]   # 相邻词间隔
# 好的结果：p50 ≈ 0.00，p90 ≈ 0.00，max < 1.0
# 差的结果：p50 ≈ 0.15~0.3（到处是人为插入的静音）
```

## 9. ★交付前自动验收（配音跑完立刻跑）

```python
# 1) 句末丢字：ASR 全文 vs 原文（先去标点再比）
#    ★原文含标点、ASR 输出无标点，直接比会误判成「丢字 15~20%」
#    判定：连续 2 字以上缺失且非英文/数字 → 真丢字，必须修

# 2) 句首杂质：每个长静音（>=0.4s）后的起音峰值
for a, b in long_silences:
    pk = abs(x[b*win : b*win + int(sr*0.06)]).max()
    if pk < 0.15:   # 真语音应该 0.15~0.9
        报出来()

# 3) 拼接爆音：只看长静音的边界，检查前后一个样本
pre, post = abs(x[i0-1]), abs(x[i1])
if pre > 0.03 or post > 0.03:
    报出来()
# ★绝对不要用「相邻样本差 > 0.08」——正常语音的塞音/擦音会误报（17s 能报 94 处，全是假的）

# 4) 复读：准备「参考音频独有词」清单，ASR 转写后看是否命中
```

**抽验必查的 3 类段**（不用全跑 ASR）：

1. 含最多英文词的那段
2. 含句末轻声最多的那段（「……什么都没干」「……都必须立刻停」）
3. 含多音字的那段（「一千行」「转起来」）

## 10. 五类故障速查

| 症状 | 根因 | 解法 |
|---|---|---|
| **句末最后几个字没了**（最严重） | ① 淡出 28ms 削尾音 ② 尾部阈值 0.08 把轻声当静音 | 淡出改 6ms；尾部单独用 0.015 + 40ms |
| **句首一声「杂质」** | 头部阈值 0.02 太松，噪声被当起音 | 阈值提到 0.08 + 连续 3 帧 |
| **句间「啪」爆音** | 首尾残留非零样本 + DC 偏移 | 去均值 → trim → 6ms 淡化，三步缺一不可 |
| **英文读成中文腔** | zero_shot 保留中文音素 | 音译 + 分开拼写，接受少数词略偏 |
| **音色漂了** | 用了 cross_lingual | 不要用 cross_lingual，音色优先 |

## 11. 句末最后一个字「没读出来」怎么办

CosyVoice 偶发，且**按结尾余量筛不出来**（正常句子末字也只有 0.15~0.45s）。

判断方法：把最后 1.5~2s 切出来单独 ASR，看最后一个字是否还原。

```python
sf.write('_tail.wav', a[int(sr*(dur-2)):], sr)   # 再跑一次 whisper
```

修法优先级：

1. **换结尾词** —— 把「什么该看。」改成「什么该看，什么该丢。」，落在开口度大的「丢」上
2. 重配整段碰运气

改词要连页面上的同一句话一起改，并且：**改讲稿文字 → 该段音频时长变 → 该页必须重渲染 → 必须重合成**，三步缺一不可。
