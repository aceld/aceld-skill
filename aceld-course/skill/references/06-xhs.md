# 06 · 小红书图卡（1080×1440）

## 1. 和长文是两个物种

| | 图文长文 | 小红书图卡 |
|---|---|---|
| 目的 | 讲完整 | 一页一个钩子 |
| 长度 | 8000~15000 字 | 每页 ≤ 40 字 |
| 图 | 9 张示意图 | 10 张竖版图卡 |
| 读者状态 | 主动学习 | 被动滑动 |

同样一节课，长文配 9 张图；小红书是 10 张图、每张一句话。

## 2. 规格

| 项 | 值 |
|---|---|
| 画布 | 1080 × 1440（3:4，小红书竖版最佳比例） |
| 渲染 | viewport 1080×1440 + `device_scale_factor=2` → 截图后 LANCZOS 缩回 1080×1440 |
| 体积 | 每张 150~200 KB，10 张约 1.8 MB |
| 安全边 | 左右各 88px、上下 96px；底部 52px 留给署名 + 页码 |

## 3. 版面骨架

```
kick     小标签：— 03 · 第 1 代 · RAG      （accent 色 + 26×3 短横）
big      主标题：88px / 800 / 行高 1.2       （一行一个意思，最多三行）
内容块    卡片 / 大字数字 / SVG
one      底部一句话：31px，左边 6px accent 竖条
foot     左下 署名，右下 01 / 10
```

### 3.1 整页垂直居中

用 `margin-top:auto` 把底部那句话顶到底，内容少的时候中间会空出一大块（实测空过 400px）。

改成整页 `justify-content:center`，`one` 用固定 `margin-top:34px`，所有页的留白都均匀了。

### 3.2 封面必须有「视觉锚点」

纯文字标题 + 副标题 + 关键词胶囊之后还剩一大片空白。

解法：加一排**递增的柱子**（52/72/92/112/132/152px，每级一个颜色，下面标名称），
既填了空，又把「六个阶段」讲完了。

## 4. SVG 宽度必须 ≤ 卡片内宽

卡片宽 = 1080 - 176 = 904，减去左右 padding 后约 856。

`viewBox` 写 880 就会把右侧文字裁掉（实测「标记失效 + 建新边」被切掉一半）。

统一用 `width="856" viewBox="0 0 856 …"`，右栏文字从 x=634 起、19~22px 刚好放下。

## 5. 内容取舍

10 页 = 封面 + 8 个知识点 + 收尾。

- 每页只回答**一个问题**
- 数字优先于形容词：`13 万字 → 650 字` 比「大幅压缩」有效十倍
- 标题带痛点词（「记不住事」> 「记忆管理」）

## 6. 可复用组件

`scripts/xhs_kit.py`（从多节课里抽出来的）：

| 函数 | 作用 |
|---|---|
| `page(kick, big, body, one, n, c)` | 一页完整骨架，`c` 控制 accent 色 |
| `li(no, text, sub)` | 编号条目（01 + 主文 + 灰色小注） |
| `card(lb, v, n, c)` | 卡片（标签 + 大数字 + 说明） |
| `write(dir, pages, prefix)` | 批量写出 `prefix_01.html …` |

批量渲染：

```bash
python shot_any.py <html目录> <输出目录> <前缀> <页数>
```

一套内容写完，40 张图 3 分钟出完。

## 7. 配套文案

`文案.md` 里放：

- **标题** ≤ 20 字，痛点词优先
- **正文** 约 620 字，每段 2~3 行，短句
- **话题标签** 10~12 个
- 发布时间建议

正文结构：先说结论 → 分 4~6 条讲 → 最后一句收束 + 收藏引导。

## 8. 没有讲稿的课怎么办

如果只有成片 mp4、没有文字版：

1. 用 faster-whisper 把成片转一遍（30 分钟音频约 4 分钟）
2. 按**操作步骤**而不是**知识结构**组织图卡

实操课的正确结构是「装环境 → 填 Key → 说人话 → 看账单」，不是概念递进。
