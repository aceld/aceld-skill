# 05 · 图文长文

## 1. 铁律：配图一律重绘，禁止截成片帧

截图会带上主播小窗、字幕、面包屑，进文章立刻掉档。

**正确做法**：每张图写成一个自包含 HTML，用 Playwright 按 2 倍缩放截图。
一套图 = 一个 `fig.css` + `fig1..N.html` + 一个 `shot_figs.py`。

```
work/figs/
├─ fig.css          共用变量 + 卡片/胶囊/注释条
├─ fig1..9.html     每张图一个自包含 HTML（<link> 引 fig.css）
└─ shot_figs.py     Playwright 1280 宽、device_scale_factor=2 → 2x PNG
```

## 3. 文章结构模板

```markdown
# <系列名>（第X课）：主标题 —— 副标题

> 引入（一两句话点出本课要解决的问题）+ 上节回顾 + 本课讲什么

## 开场：N 个现象（勾起兴趣）
（配图: fig1）

## 一、xxx
### 1.1 xxx
（配图: fig2）

### 1.2 xxx
…

## 二、xxx
…

## 本篇总结：五句话记住这节课
（全景表）

## 下节预告
<签名>
```

写作约束：

- 段落 ≤ 5 句，一段只讲一件事
- 禁「首先 / 其次 / 最后 / 综上所述」
- 禁「很多 / 一些 / 非常」这类模糊词，用具体数字
- 核心结论加粗
- 术语首次出现必须解释
- 每节配一张图（`![](文章配图/figN.png)`）

**实操类课程**：每步带命令 + 界面截图占位（「界面如下：」）
**原理类课程**：每节配图 + 生活类比 + 表格总结

## 4. 三个必踩的坑

### 4.1 `full_page=True` 底部出大片空白

内容比 viewport 短时，Playwright 按 viewport 高度出图。

→ 拿到 `body.scrollHeight` 后用 PIL 按 `h * 2` 再裁一次。

### 4.2 一排卡片底部色条不对齐

卡片必须 `display:flex; flex-direction:column`，色条/统计条 `margin-top:auto`。

### 4.3 SVG 里文字压在线上

连线标注、负收益区的文字默认压线，必须手算 y 偏移。
面积填充的起点要落在曲线穿过零线的那一点。

## 5. HTML 预览

`md2html.py`（markdown 3.x + tables / fenced_code / nl2br）：

- 正文 800px，图片 960px 出血（`.page` 1040 宽 + `p,table,h2…{max-width:800px}`）
- `strong` 用淡黄记号笔底纹
- 同一份 md 直接能粘进公众号编辑器（见 `08-wechat.md`）

> 如果运行环境拦截了 `pyexpat` DLL 导致 markdown 库不可用，
> 可以写一个零依赖的极简转换器（标题/粗体/引用/代码块/表格/图片/列表/水平线），
> 几十行就够，不必为这个装环境。
