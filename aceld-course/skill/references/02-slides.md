# 02 · 动画幻灯片

## 1. 设计系统

现代深色科技风。CSS 变量集中在 `scripts/gen_common.py` 的 `CSS` 字符串里：

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg0` | `#070b16` | 主背景 |
| `--bg1` | `#0d1428` | 渐变中间 |
| `--bg2` | `#141d38` | 渐变末端 |
| `--ink` | `#e8eeff` | 主文字 |
| `--dim` | `#93a4c9` | 次要文字 |
| `--faint` | `#5f7093` | 辅助文字 |
| `--cyan` | `#22d3ee` | 强调色 1 |
| `--violet` | `#a78bfa` | 强调色 2 |
| `--gold` | `#fbbf24` | 强调色 3 |
| `--red` | `#fb7185` | 警告 |
| `--green` | `#34d399` | 成功 |

- 画布 **1920×1080**，内边距 `104px 92px 140px 92px`（底部多留，给字幕带让位）
- 背景：两个径向光斑 + 网格线 + 线性渐变
- 字体：`Microsoft YaHei` / `PingFang SC`，代码用 `Consolas`
- 三处固定元素：左上面包屑（章节）、右上署名 + 页码、可选中部斜向水印

## 2. 页面定义格式

每页是一个 tuple，追加到模块级 `S` 列表：

```python
S.append((sid, "章节名", 总页数, r"""
<div class="inner">
  <h1 id="t0">页面标题</h1>
  <div class="card" id="c1">…</div>
</div>""", [
    # 步骤表：[触发词, 选择器, 动效, 持续秒]
    ("先给你一张地图", "#t0", "fadeUp", 0.6),
    ("第一块",        "#c1", "fadeUp", 0.5),
]))
```

> 老版本用 `[句序号, 句内偏移秒, 选择器, 动效, 持续秒]`，靠「第几句 + 偏移」定位。
> **已经弃用**：改讲稿就要重算全部时间。新写法用触发词，见第 4 节。

## 3. 动效库

`gen_common.py` 的 `FX` 对象里定义，全部只操作 `opacity` / `transform` / `filter`，逐帧可精确复现：

| 名称 | 效果 | 注意 |
|---|---|---|
| `fadeUp` / `fadeLeft` / `fadeRight` | 淡入 + 位移 | 最常用 |
| `fadeIn` | 纯淡入 | 虚线、连接线用它 |
| `pop` | 弹出放大 | 强调单个元素 |
| `growX` / `growY` | 从 0 生长 | 进度条、柱子 |
| `count` | 数字递增 | 需 `data-from/data-to/data-dec` |
| `hl` | 高亮闪烁 | **只适合代码行**，用在整块 card 上会变成刺眼黄框 |
| `dim` | 变暗 | 强调对比 |
| `rise` | 上浮 + 微缩放 | 卡片入场 |
| `type` | 打字机 | 需 `data-text` |
| `draw` | SVG 描线 | **会覆盖 `stroke-dasharray`，虚线不能用** |

`NOHIDE = {hl, dim, count, pulse}` —— 这几个效果不改 opacity，元素初始就不隐藏。

## 4. 动画顺序铁律（最容易出错的地方）

### 4.1 一块内容 = 一个 id = 一个触发词

| 毛病 | 根因 | 表现 |
|---|---|---|
| 一次全出来 | id 打在**容器**上（一个 `#box` 包住 6 个块） | 讲到第一块，六块一起亮 |
| 有的块永远不出来 | 只给**部分**子元素打了 id | 没 id 的元素跟着页面出现，或永远停在 opacity:0 |

```python
# ✅ 六块各一个 id，各自绑定讲稿里那句话
[("先给你一张地图", "#r0", "fadeUp", 0.6),
 ("第一块",        "#r1", "fadeUp", 0.5),
 ("第二块最重",     "#r2", "fadeUp", 0.5),
 ("第三块",        "#r3", "fadeUp", 0.5),
 ("第四块",        "#r4", "fadeUp", 0.5),
 ("第五块",        "#r5", "fadeUp", 0.5),
 ("好，地图给完了",  "#r6", "fadeUp", 0.6)]
```

### 4.2 ★编号错位（实际踩过）

讲稿说「第一块」时，映射到的却是第 0 号元素，结果**每个模块都提前一个**。

```python
# ❌ 内容块从 0 开始编号，标题没 id
for i, x in enumerate(items):
    id = f"r{i}"                                  # r0..r5 是内容
steps = [("先给你一张地图", "#r0"), ("第一块", "#r1")]   # 错位一个

# ✅ 标题占 0 号，内容从 1 开始
<h1 id="r0">…</h1>
for i, x in enumerate(items):
    id = f"r{i+1}"                                # r1..r6 是内容
steps = [("先给你一张地图", "#r0"), ("第一块", "#r1")]
```

**规矩：凡是讲稿里会说「第一/第二/第三…」的页面，内容块 id 必须从 1 开始，标题单独占 0 号。**
这种错位静态校验查不出来，只能渲染完抽查一页，看第 N 块是不是在第 N 句出现。

### 4.3 ★无 id 的装饰元素会「先出来」（最高频 bug）

用户反馈里最常见的一句是「**这页动画顺序有问题，有的先出来了**」。
根因几乎永远是同一个：**渲染器把「不在任何 step 里」的元素当成常驻可见**，
所以它们从第 0 帧就在画面上，而语音还没讲到。

典型肇事者——都是「装饰性」的，容易被漏掉：

| 元素 | 为什么会漏 | 现象 |
|---|---|---|
| 连接箭头 / 引导线 | 以为是背景装饰 | 内容还是空的，箭头先连好了 |
| 红色警示标题 / 「注意」条 | 以为是页面固定元素 | 讲到「这里有个坑」之前红字已经在 |
| 整改卡 / 结论框 | 后加的，加时忘了挂 step | 最后一个框先出现 |
| 虚线分组框 | 同上 | 空框先画好，内容一个个填 |

**修复三步**：

1. 给元素加 `id`（哪怕是纯装饰）
2. 在 `steps` 里挂**它内容对应的那句触发词**
3. 重跑 `build_deck.py`，确认「孤儿 id」校验通过（4.5 节）

```python
# ❌ 箭头没 id → 第 0 帧就可见
'<path d="M100 200 L100 300" stroke="#888"/>'

# ✅ 箭头挂到「第一层日志，一个字不删」这句，跟内容一起揭示
'<path id="arw1" d="M100 200 L100 300" stroke="#888"/>'
...
("第一层日志", "#arw1", "fadeIn", .3),
```

**自检口诀**：**页面上任何一个看得见的东西，都必须回答「我在哪个 step 里」**。
答不上来的，就是下一个「先出来」。

### 4.3.1 ★`draw` 不能用于整段竖线

`draw` 动效靠 `getTotalLength()` + `strokeDasharray/strokeDashoffset`。
纯竖直 `<line>` / 极短 path 在某些浏览器里算出异常值，渲染出来**只剩箭头、线不见了**。

- 曲线（U 型、弧线、贝塞尔）：`draw` 好用，保留
- 整段竖线 / 横线：改成**线条静态显示 + 节点卡片逐个 `fadeUp`**，
  或者把长线拆成「线段 + 节点」分段挂 step

```python
# ❌ 竖线用 draw
("形成一个环", "#arc", "draw", .9)      # #arc 是 M44 24 V386
# ✅ 竖线常驻，让四个节点卡片逐个出现，箭头单独 fadeIn
("改，验",   "#n1s", "fadeUp", .4),
("挂了就分析原因", "#n2s", "fadeUp", .4),
("再验",     "#arh", "fadeIn", .3),
```

### 4.4 三条硬约束（`build_deck.py` 内置校验）

1. 选择器必须存在于该页
2. 触发词必须是该段正文的原样子串
3. **触发词在正文里的位置必须严格递增** —— 倒退就说明「动画跑到语音前面去了」

### 4.5 还要查「从未出现」

把页面里所有 `id="xxx"` 和 steps 里用到的 `#xxx` 做差集，非空就是有内容永远不会亮。
（`svg` 里的 `marker id` 除外；代码行锚点除外——非锚点行由级联跟进。）

### 4.6 触发词怎么选

挑讲稿里**那一块内容第一次被提到**的那几个字，不要用段尾的总结句。

反面例子：把「整个过程没人盯」当触发词，流程图到最后一秒才出来，等于没有动画。

真实词要选**唯一且靠前**的子串。同一句话里出现两次时，写长一点：
`"第零代"` → `"第零代，没有记忆"`。

选完打印一遍 `text.find(w) / len(text)`，跟预期位置对一下。

### 4.7 ★build 通过 ≠ 触发词命中

`build_deck.py` 对未命中的触发词**不报错**，直接退回「按步号均匀铺开」。
所以必须单独跑命中检查（脚本里已内置 `check_cues`，输出必须为 0 条）：

```python
for i, (h, steps) in enumerate(P):
    t = S[i]["text"]
    for st in steps:
        c = str(st[0])
        if not c.startswith("@") and t.find(c) < 0:
            print("P%d %s 未命中 %r" % (i, st[1], c))
```

## 5. 代码页：逐行出现

- 每行代码带 `id="codel{N}"`
- 锚点行由触发词定时，**锚点之间的行按 `0.10s/行` 级联跟进**
- 讲稿按行讲：「第二行，第一步，装配……第四行，for 循环……第十一行，第三步，做……」

```python
for ln, anc in code:
    if anc and anc in anchor_t:      # 有触发词的行走自己的时间
        continue
    prev = [x for x in anchors if x[0] < ln]
    t = anchor_t[prev[-1][1]] + min(1.0, (ln - prev[-1][0]) * 0.10)
```

代码页讲稿会变长（200 字 → 400 字），**这是对的**，不要为了控时长砍掉。
「刚放完代码就翻页、一闪而过」是最容易被退回的问题之一。

## 6. 渲染管线

```
deck_a.py / deck_b.py  (页面定义)
    ↓ build_deck.py     组装 + 校验
deck.html + deck_meta.json
    ↓ render_slides.py  逐帧渲染
clips/slide_XX.mp4 + slide_timeline.json
```

- 用 Playwright + 系统 Chrome，`viewport 1920×1080`，`device_scale_factor=1`
- 只渲染动画窗口内的帧（静止期靠重复帧填充），约 90ms/帧，30 页约 3000 帧 → 5~12 分钟
- 每页结尾多留 **`TAIL=0.70s`**，必须与合成脚本的段间停顿一致

### 6.1 ★静止帧填充：必须用硬链接帧序列

| 做法 | 结果 |
|---|---|
| concat + `duration` + `-fps_mode cfr -r 30` | 帧数对，但 VFR→CFR 重采样的时间戳语义不透明，无法验证 |
| concat 里把同一个 PNG 重复写 N 次 | ❌ `DTS -230584300921369 invalid dropping`，clip 只剩 4 帧 |
| **按 duration 建硬链接，生成 `seq/00000.png…` 真实序列** | ✅ 帧号 = 时间 × 30，可验证 |

```python
seqdir = os.path.join(fdir, "seq")
n_out = 0
for k, pth in enumerate(paths):
    d = (times[k+1] - times[k]) if k+1 < len(times) else (dur - times[k])
    n = max(1, int(round(d * FPS)))
    for _ in range(n):
        dst = os.path.join(seqdir, "%05d.png" % n_out)
        try:
            os.link(pth, dst)        # 同 inode，不占空间
        except OSError:
            shutil.copy(pth, dst)
        n_out += 1
# ffmpeg -framerate 30 -i seq/%05d.png -r 30 -c:v libx264 ...
```

硬链接不占磁盘：1881 帧仍然只有 178 个 inode。**输出帧数 = 时长 × 30，可以直接当验收指标。**

## 7. 版式坑

1. **内容全堆在上半屏** → `.inner` 加 `display:flex; flex-direction:column; justify-content:center`
2. **`hl` 不能用在整块 card 上** → 会变成刺眼的黄框，只适合代码行
3. **`hl` 不设 opacity** → 元素若被 `resetAll()` 置 0 会一直不可见。修法：`NOHIDE` 里加上 `hl`，包装时先设 `opacity`
4. **彩色 emoji 在无头 Chrome 下退化成白色剪影** → 改用「中文字牌」（圆角方块里放单个汉字）
5. **预览脚本的选择器必须和渲染器一样加 `#slide{i}` 前缀** → 否则跨页同名 id 互相污染
6. **时序图的框也要有出现时机** → 用触发词控制整个 `#seqbox` 淡入，别一进页面就摆在那
7. **页面里的小箭头（→ ↓）也要加 id 和 step** → 否则跟着页面一起出现，顺序就乱了
8. **`draw` 会把虚线渲染成实线** —— 它无条件覆盖 `stroke-dasharray`。虚线元素用 `fadeIn`，实线才用 `draw`。讲稿提到「虚线/实线」时必须回成片核对

## 8. 坐标图

### 8.1 两条线做「代价」标注，不要放两个错位的圆点

第一版在曲线上放「字数 ×2」和「代价 ×4」两个点，但两点 x 坐标不同，观众看不出是一组对照，反而更糊涂。

改成：

1. 两条线之间用闭合 path 填一层淡色（`M<曲线> L<终点> Z`，曲线原样反向接回直线）→「岔开的那一段」自动长出来
2. 在同一个 x 上画一条**竖直双向箭头**连接两线，旁边贴一行「岔开的这一段 / 就是你要付的钱」
3. 文字别压在填充区上，放到线下方空白处，或加 `rgba(255,255,255,.94)` 圆角底片

```xml
<path id="area" d="M90 396 C 330 386, 560 300, 828 50 L 828 240 Z"
      fill="url(#ag)" opacity="0"/>
```

### 8.2 「线性 vs 平方」两条线容易画反

归一化到同一终点后，平方曲线前期反而在下方。正确做法是**让红线终点明显更高**
（如紫线到图高 40%、红线到 90%），这样中后段红线陡升，视觉上才符合「平方增长更快」。

### 8.3 拐点标签

别贴在轴线上（会被读成轴标签），用白色小圆角 chip 挂在竖直虚线的中段。

## 10. 章节主标题加「耳熟能详的简称」
